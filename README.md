# ⏳ ChronoVault

ChronoVault is a full-stack MERN application that lets users create encrypted digital time capsules to be opened in the future.

---

## 🚀 Features

- 🔐 Secure User Authentication (JWT)
- ⏳ Create Digital Time Capsules
- 🔒 AES Encryption
- 📅 Countdown Timer
- 🖼 Upload Images & Videos
- 🤖 AI Reflection Generator
- 📧 Email Reminder Notifications
- 🌙 Dark Mode
- 📱 Fully Responsive Design

---
